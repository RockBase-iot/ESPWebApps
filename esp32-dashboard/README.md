# esp32-dashboard

An e-paper dashboard running on ESP32. The current version features a fully functional weather station powered by the free Open-Meteo API — no API key required — showing current conditions, a 5-day forecast, an hourly temperature / precipitation graph, air quality, and indoor sensor data.

Firmware package for ESP web flashing.
